Fix the blank AI panel when switching back to AI Hub.

The last selected app now returns above the workspace when you switch back from another window. You no longer need to click its sidebar button again. Focus restoration waits for mouse presses to finish so sidebar clicks can complete. The hub does not cover other applications while it is in the background.

App switching, pop out, original window restoration, usage monitoring and automatic updates retain their existing behavior. The fix includes an interactive regression fixture that checks five away/return cycles using disposable windows.

Existing v0.3.0 installations receive this update through the public release channel. Choose **Settings → Check for updates**, then **Restart to update**, or let the downloaded update install when AI Hub closes. New installations can download the Windows x64 ZIP and verify it with SHA256SUMS.txt.

Built and validated locally without GitHub Actions minutes.
