## Install

Download **[AIHub-v0.5.0-windows-x64-Setup.exe](https://github.com/wernerong/ai-hub/releases/download/v0.5.0/AIHub-v0.5.0-windows-x64-Setup.exe)** and double-click it. Close AI Hub first if upgrading.

Setup installs for your Windows account with Start menu and optional desktop shortcuts, plus a native uninstaller in Windows Installed apps. No PowerShell commands, execution-policy changes, ZIP extraction or administrator access are needed. Existing settings and AI apps are preserved.

This release is unsigned, so Windows may still show a SmartScreen or unknown-publisher warning. SHA-256 checksums are included with the release.

## Choose the AI apps you use

- Right-click any AI in the sidebar and select **Remove from AI Hub**. Installed and open apps stay hidden after removal, including across restarts.
- Use **+ / Connect an AI** to remove apps or choose a removed app and **Add back to AI Hub**.
- Removing a hosted AI restores its original window. It does not uninstall the app or erase its account. Usage monitoring remains independently configurable in Settings.
- Claude now uses its official Windows app icon.

## Updates and validation

The existing automatic update channel continues to work through the ZIP asset. Updates preserve the native uninstaller, settings, provider logins and connections. The ZIP is also available for portable use; Setup.exe is the recommended download for installation.

The package includes the Windows self-test report. Native setup is separately checked for clean installation, upgrade, legacy registration migration, running-app protection, shortcut creation and uninstall. The native installer does not change PowerShell execution policies.
