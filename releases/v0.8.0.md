# AI Hub v0.8.0

Use GitHub Copilot directly inside AI Hub, with a model selector, streamed chat, project folders, saved conversations, tool activity, permission controls and Stop. VS Code is not required.

Open **Copilot → Install runtime** to download and verify the official native Windows runtime, then **Sign in**, choose a working folder and **Connect**. No Node.js, administrator rights or separate terminal installation is needed. Existing native Copilot installations can also be detected.

Chats are saved separately for each project and personal workspace. Deleting a project moves its chats to the personal workspace. Copilot's advertised models, account policies and usage limits apply. The bottom strip shows session status and reported context tokens; these are separate from your account allowance. VS Code chats and tokens are not imported.

Copilot uses its own full workspace. Existing app panels and their split view remain available, and Copilot can be removed or restored like other sidebar entries. Closing AI Hub saves and stops its owned Copilot session and retains the existing connected-window shutdown behavior.

Validation: 428 automated checks pass, including existing docking, taskbar, shutdown and recovery behavior. Copilot layout and permission controls were rendered and inspected at the laptop's display scaling. An authenticated live check verified model discovery and selection, one streamed response, and conversation resume in a fresh runtime process.
