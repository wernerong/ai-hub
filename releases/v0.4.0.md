AI Hub now adapts to the AI apps installed or open on each person's computer. Unused providers stay out of the sidebar. Use **Connect an AI** for another desktop app or a dedicated browser window; custom connections are remembered locally.

The usage command center has a new dark HUD design with cyan allowance rings, amber warnings, reset countdowns and clear remaining percentages. It adapts to the available, enabled monitors, including one or none. Supported usage readers remain Codex CLI, Grok CLI / Build and Grok Bot; other connected apps do not receive invented usage readings.

Existing app logins, zoom choices, usage preferences, window recovery and the return-to-app focus fix are preserved. Custom browser connections match the selected title and may need reconnecting after a title change across window launches.

Download the Windows x64 ZIP, verify `SHA256SUMS.txt`, and run `Install-AIHub.ps1`. Existing public-release installations receive this update automatically, or use Settings → Check for updates → Restart to update.

Built and validated locally, with no GitHub Actions jobs or minutes.
