Initial public release of AI Hub for Windows x64.

Bring your installed OpenAI (ChatGPT, Codex and Dot), Grok and Cursor Grok Bot windows into one workspace. Provider icons, saved content zoom, integrated Codex/Grok CLI/Grok Bot usage monitoring and window recovery are included.

Download **AIHub-v0.3.0-windows-x64.zip**, verify it against **SHA256SUMS.txt**, and extract it. Run `Install-AIHub.ps1` in PowerShell for a per-user install with shortcuts and an entry in Windows Installed apps, or run `AIHub.exe` from a writable folder. The .NET runtime is included; the provider apps must already be installed.

Automatic updates use this repository's published stable releases. AI Hub checks at startup and every six hours, verifies the package checksum, and installs when the hub closes after restoring its app windows. Settings also offers **Check for updates**, **Restart to update**, and an automatic-update switch. GitHub sign-in is not required for updates. Existing 0.2.1 and earlier builds need this one manual upgrade to gain the updater.

The build and validation run locally; publishing and app updates require no GitHub Actions jobs or private-repository minutes. The package includes the complete automated validation report, including update staging, cancellation, tamper rejection, rollback and a detached helper handoff using disposable processes.

This is an early 0.x Windows release. Broader multi-monitor, virtual desktop, and voice/video compatibility testing is still pending. Quota readers cover the named products only; a provider with an expired login is shown as unavailable. Provider artwork identifies the corresponding third-party apps and belongs to its owners.
