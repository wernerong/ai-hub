AI Hub v0.6.0 adds project continuity: save the apps and context for each kind of work, resume your workspace, and find actions from one command palette.

## Projects and resume

- Open **Projects**, choose **+ New project**, and save a name, AI app choices, notes, web links and folder paths. **Save current** also captures the hub's size, position and maximized state.
- **Open workspace** reconnects saved apps and returns to the selected AI. Unavailable or removed apps remain in the project for later use. Ambiguous windows and browser connections that need reassignment are left for you to choose.
- The last workspace resumes by default. The **Resume the last workspace when AI Hub starts** checkbox saves immediately, separately from unsaved project edits. Turn it off to start in the personal workspace.
- Notes and resources stay local. Open resources explicitly or use **Copy project notes** to prepare a handoff. AI Hub does not read provider chat histories or restore a particular conversation.

## Commands and browser connections

- Press **Ctrl+Alt+Space** or select **Commands** to search projects, available AI apps and actions. **Ctrl+K** works while AI Hub itself has focus. Arrow keys select a result, Enter runs it, and Escape cancels.
- Search for **Change command shortcut** to choose Ctrl+Alt+K, Ctrl+Alt+P, the default Ctrl+Alt+Space, or Disabled. An occupied shortcut does not replace a working choice.
- Saved custom connections remain visible while closed. If a browser title changes, select its sidebar button and choose the correct replacement window, or use **Reconnect saved browser** in **+ / Connect an AI**. The connection keeps its name and identity, preserving project membership.

Projects and resume preferences are stored in `%LOCALAPPDATA%\AIHub\workspaces.json`; the command shortcut is stored in `command-shortcut.json` alongside it. Provider accounts and conversations remain with their apps.

## Install and update

Download **[AIHub-v0.6.0-windows-x64-Setup.exe](https://github.com/wernerong/ai-hub/releases/download/v0.6.0/AIHub-v0.6.0-windows-x64-Setup.exe)** and double-click it. Close AI Hub first when installing manually over an existing copy. The per-user native installer and uninstaller introduced in v0.5.0 remain supported. This release is unsigned; it does not remove Windows publisher or SmartScreen warnings.

Existing installations receive v0.6.0 through the public release updater using the ZIP asset. The installer, portable/update ZIP and `SHA256SUMS.txt` are included. Packaging runs the Windows self-test locally and includes its validation report; builds and publication use zero GitHub Actions minutes.

Split view, shared context handoffs and usage history belong to the next planned phase and are not included in this release.
