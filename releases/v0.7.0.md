AI Hub v0.7.0 lets you work with two AIs together, prepare explicit context handoffs and plan around locally recorded quota usage.

## Two-AI workspaces

- Select **Split view**, choose two different apps, then **Open split**. Use side-by-side panes or **Stack vertically (top and bottom)**.
- The cyan **FOCUSED** header shows which AI receives sidebar replacements. Selecting the AI already in the other pane focuses it without creating a duplicate.
- Drag the divider to save its ratio, or run **Swap split panes** from Commands. Choose **Single AI** in the layout dialog to return to one app. **Pop out** restores the focused app's original window and expands the remaining AI.
- Sessions and saved projects retain supported split layouts, orientation, ratio and focus. Both panes follow minimize/restore and native window recovery.

## Context shelf and handoffs

**Context shelf** saves titled snippets, instructions and file references for each project, with separate personal context. Check the items to include and edit **Goal**, **Decisions**, **Evidence**, **Constraints** and **Next step**. Project notes are included only when explicitly checked.

Review **Exact preview**, then choose **Copy** or **Copy & open target**. Both save the draft and copy the rendered handoff; the latter also opens or focuses the chosen AI after copying succeeds. Paste the handoff yourself and attach referenced files manually. AI Hub does not read referenced file contents, upload files, import provider chats or automatically send the handoff.

## Local usage history

Open **Usage → Usage history**, or find it in Commands, for per-product quota charts and reported reset times. Recording is enabled by default, uses fresh numeric readings already collected by the monitor, and adds no provider requests. **Record usage locally** and **Clear history** control local samples independently of provider allowances.

History retains up to 30 days and 50,000 samples. It stores provider/quota identifiers, percentages and fetch/reset times, excluding balances, account details, tokens and chat content. Clear it after switching provider accounts.

Consumption forecasts are labeled **Estimate**. They need a fresh reading and at least three comparable readings over five minutes in the same reset window. Changed resets, decreasing usage and gaps over ten minutes restart the comparison; missing or insufficient data stays unavailable. Estimates use up to six hours of recent observations, and future usage may differ. Codex, Grok CLI / Build and Grok Bot remain separate usage scopes.

## Install and update

Download **[AIHub-v0.7.0-windows-x64-Setup.exe](https://github.com/wernerong/ai-hub/releases/download/v0.7.0/AIHub-v0.7.0-windows-x64-Setup.exe)** and double-click it. Close AI Hub before manually upgrading. Native per-user installation and uninstall remain supported. The installer is unsigned; Windows may show publisher or SmartScreen warnings.

Existing installations receive v0.7.0 through the public release updater. The native installer, portable/update ZIP and `SHA256SUMS.txt` are included. Packaging runs the Windows self-test locally and includes its validation report. Builds and publication use zero GitHub Actions minutes.

Workspace, shelf and usage history data stay under `%LOCALAPPDATA%\AIHub`. Existing provider accounts and conversations remain in their apps.
